# 1. IMPORT REQUIRED LIBRARIES

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# ============================================================
# 2. LOAD THE DATASET
# ============================================================

# Load the dataset

df = pd.read_csv(
    r"C:\Users\HP\Downloads\city_day.csv"
)

print("Dataset Loaded Successfully!")

print("\nFirst Five Records:")
print(df.head())

print("\nColumn Names:")
print(df.columns.tolist())
# ============================================================
# 3. EXPLORE THE DATASET
# ============================================================

print("\nDataset Shape:")
print(df.shape)

print("\nDataset Information:")
df.info()

print("\nStatistical Summary:")
print(df.describe())

print("\nColumn Names:")
print(df.columns.tolist())

print("\nMissing Values:")
print(df.isnull().sum())

# ============================================================
# 4. DATA CLEANING AND PREPROCESSING
# ============================================================

# Clean column names

df.columns = df.columns.str.strip()

# Convert date column into datetime format

df["Date"] = pd.to_datetime(df["Date"], errors="coerce")

# Convert numerical columns

pollutants = ["PM2.5", "PM10", "CO", "AQI"]

for col in pollutants:

    if col in df.columns:

        df[col] = pd.to_numeric(
            df[col], errors="coerce"
        )

# Handle missing numerical values

for col in pollutants:

    if col in df.columns:

        df[col] = df[col].fillna(
            df[col].median()
        )

# Remove duplicate records

df.drop_duplicates(inplace=True)

# Remove records with invalid dates

df.dropna(subset=["Date"], inplace=True)

# Sort data by date

df.sort_values("Date", inplace=True)

print("\nCleaned Dataset:")
print(df.head())

# ============================================================
# 5. IDENTIFY RELEVANT VARIABLES
# ============================================================

print("\nRelevant Variables:")

print("Date: Time period of air quality measurement")

print("PM2.5: Fine particulate matter")

print("PM10: Coarse particulate matter")

print("CO: Carbon Monoxide")

print("AQI: Air Quality Index")

plt.plot(

correlation = df[

# ============================================================

daily_summary = df.groupby(
    df["Date"].dt.date
).agg({

    "AQI": "mean",

    "PM2.5": "mean",

    "PM10": "mean",

    "CO": "mean"

})

print("\nDaily Air Quality Summary:")

# ============================================================

print("\nAIR QUALITY STATISTICS")

print("Average AQI:", round(df["AQI"].mean(), 2))

print("Minimum AQI:", df["AQI"].min())

print("Average PM2.5:", round(df["PM2.5"].mean(), 2))

print("Average PM10:", round(df["PM10"].mean(), 2))

print("Average CO:", round(df["CO"].mean(), 2))

df.to_csv(

print("\n========================================")

## Data Visualization is the process of representing data in graphical form, such as line plots, bar charts, scatter plots, and heatmaps.
Step 1: Import Required Libraries
We use four Python libraries:
- Pandas: Used to load and manipulate the dataset.
- NumPy: Used for numerical operations.
- Matplotlib: Used to create graphs and charts.
- Seaborn: Used for statistical visualization, such as violin plots and heatmaps.

Step 2: Load the Dataset
- The air quality dataset is loaded from a CSV file.
- The dataset is stored in a DataFrame named df.
- The first five records are displayed.
- Column names are displayed to understand the available information.

Step 3: Explore the Dataset
In this step, we examine the dataset.
- Shape: Displays the number of rows and columns.
- Info: Displays column names and data types.
- Describe: Provides statistical information such as mean, minimum, maximum, and standard deviation.
- Isnull: Identifies missing values.

Step 4: Data Cleaning and Preprocessing
Data cleaning is performed to improve the quality of the dataset.

The following operations are performed:
1. Clean Column Names: Removes unnecessary spaces from column names.
2. Convert Date: Converts the Date column into datetime format.
3. Convert Numerical Columns: Converts PM2.5, PM10, CO, and AQI into numerical format.
4. Handle Missing Values: Missing numerical values are replaced using the median.
5. Remove Duplicates: Removes repeated records.
6. Remove Invalid Dates: Removes records where the date is missing or invalid.
7. Sort Data: Arranges records according to date.

Step 5: Identify Relevant Variables
In this step, we identify the important variables used for analysis.
Variable	Meaning
Date	Date of air quality measurement
PM2.5	Fine particulate matter
PM10	Coarse particulate matter
CO	Carbon Monoxide
AQI	Air Quality Index


Important terms:
- PM2.5: Very small particles that can enter deep into the lungs.
- PM10: Particles with a diameter of 10 micrometres or less.
- CO: Carbon monoxide is a harmful gas.
- AQI: Indicates the level of air pollution.
Step 6: Line Plot – Overall AQI Trend
- A line plot is created to show AQI values over time.
- Date is displayed on the X-axis.
- AQI is displayed on the Y-axis.
- Markers represent individual data points.
- Grid lines make the graph easier to understand.

Step 7: Line Plot – PM2.5 Trend
- A line plot is created for PM2.5 concentration.
- Date is displayed on the X-axis.
- PM2.5 concentration is displayed on the Y-axis.

Step 8: Line Plot – PM10 Trend
- A line plot is created to display PM10 levels.
- It shows changes in coarse particulate matter over time.

Step 9: Line Plot – CO Trend
- A line plot is created for Carbon Monoxide.
- Date is displayed on the X-axis.
- CO concentration is displayed on the Y-axis.

Step 10: Bar Plot – AQI Values by Date
- A bar chart is created to compare AQI values across different dates.
- Each bar represents the AQI value for a particular date.
- The height of each bar represents the AQI level.

Step 11: Stacked Bar Plot – Pollutant Levels
- A stacked bar chart is created to display PM2.5, PM10, and CO levels.
- Different pollutants are represented using separate bar sections.
- Each section represents the value of a particular pollutant.

Step 12: Box Plot – AQI Distribution
- A box plot is created to understand the distribution of AQI values.
- It displays the median, quartiles, and potential outliers.

Step 13: Violin Plot – AQI Distribution
- A violin plot is created using Seaborn.
- It displays the distribution and density of AQI values.
- Wider portions indicate where more observations are concentrated.

Difference between Box Plot and Violin Plot:
- Box Plot shows median, quartiles, and potential outliers.
- Violin Plot shows the distribution and density of data.

Step 14: Scatter Plot – AQI vs PM2.5
- A scatter plot is created to compare PM2.5 with AQI.
- PM2.5 is displayed on the X-axis.
- AQI is displayed on the Y-axis.
- Each point represents one observation.

Step 15: Scatter Plot – AQI vs PM10
- A scatter plot is created between PM10 and AQI.
- PM10 is displayed on the X-axis.
- AQI is displayed on the Y-axis.

Step 16: Scatter Plot – AQI vs CO
- A scatter plot is created between Carbon Monoxide and AQI.
- CO is displayed on the X-axis.
- AQI is displayed on the Y-axis.

Step 17: Bubble Chart – AQI and Pollutant Levels
A bubble chart is a scatter plot in which the size of each point represents an additional variable.

In this practical:
- X-axis represents PM2.5.
- Y-axis represents PM10.
- Bubble size represents AQI.
- Bubble color also represents AQI.

Step 18: Correlation Heatmap
- A correlation matrix is calculated for PM2.5, PM10, CO, and AQI.
- A heatmap is created to represent the correlation values using colors.
- Numerical correlation values are displayed inside the heatmap.
Correlation: It measures the strength and direction of the relationship between two variables.

Correlation values range from -1 to +1.
- +1: Perfect positive correlation.
- 0: No linear correlation.
- -1: Perfect negative correlation.

Step 19: Data Aggregation
Data aggregation means summarizing data using mathematical operations.

In this practical:
- Data is grouped according to date.
- Average AQI is calculated.
- Average PM2.5 is calculated.
- Average PM10 is calculated.
- Average CO is calculated.
Purpose: To obtain a daily summary of air quality measurements.

Step 20: Final Statistical Analysis
In this step, important statistical values are calculated.
- Average AQI: Represents the average air quality index.
- Maximum AQI: Represents the highest AQI value.
- Minimum AQI: Represents the lowest AQI value.
- Average PM2.5: Represents the average fine particulate matter concentration.
- Average PM10: Represents the average coarse particulate matter concentration.
- Average CO: Represents the average carbon monoxide concentration.

Step 21: Save Cleaned Dataset
- The cleaned dataset is exported into a CSV file.
- The file is saved as Cleaned_City_Air_Quality.csv.
- It can be used for future analysis.

Step 22: Final Result
At the end, the program displays:
- Total number of records.
- Total number of columns.
- Average AQI.
