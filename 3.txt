# Protein Sequence Analysis 
 
protein = input("Enter Protein Sequence: ").upper() 
 
print("\nProtein Length:", len(protein)) 
 
# Amino Acid Count 
print("\nAmino Acid Count\n") 
 
amino = "ACDEFGHIKLMNPQRSTVWY" 
 
for aa in amino: 
    count = protein.count(aa) 
 
    if count > 0: 
        print(aa, ":", count) 
 
# Approximate Molecular Weight 
weight = len(protein) * 110 
 
print("\nApproximate Molecular Weight:", 
      weight, "Daltons")

**Explanation of Protein Sequence Analysis Code (4–5 Lines)
This program performs protein sequence analysis using Python.
It accepts a protein sequence from the user and calculates its total length.
It counts the occurrence of each amino acid in the protein sequence.
It calculates the approximate molecular weight by multiplying protein length by 110 Daltons.
Finally, it displays the protein length, amino acid count, and approximate molecular weight.
