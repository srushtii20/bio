# Sales Data Analysis using CSV, Excel and JSON

import pandas as pd
import matplotlib.pyplot as plt

# 1. Load CSV file

csv_data = pd.read_csv(
    r"C:\Users\HP\Downloads\Superstore.csv",
    encoding="latin1"
)

print("Dataset Loaded Successfully!")

# Create Excel and JSON files

csv_data.to_excel("Superstore.xlsx", index=False)
csv_data.to_json("Superstore.json", orient="records")

# 2. Load data from all three formats

excel_data = pd.read_excel("Superstore.xlsx")
json_data = pd.read_json("Superstore.json")

print("\nCSV Data:")
print(csv_data.head())

print("\nExcel Data:")
print(excel_data.head())

print("\nJSON Data:")
print(json_data.head())

# 3. Check data

print("\nNull Values:")
print(csv_data.isnull().sum())

print("\nDuplicates:")
print(csv_data.duplicated().sum())

# 4. Data Cleaning

data = csv_data.dropna()
data = data.drop_duplicates()

# 5. Data Transformation

data["Order Date"] = pd.to_datetime(data["Order Date"])

data["Profit %"] = (data["Profit"] / data["Sales"]) * 100

# 6. Data Analysis

print("\nTotal Sales:", data["Sales"].sum())

print("Average Sales:", data["Sales"].mean())

print("Total Profit:", data["Profit"].sum())

print("\nSales by Category:")

print(data.groupby("Category")["Sales"].sum())

# 7. Visualization

# Bar Chart

data.groupby("Category")["Sales"].sum().plot(kind="bar")

plt.title("Sales by Category")
plt.xlabel("Category")
plt.ylabel("Sales")
plt.show()

# Pie Chart

data["Category"].value_counts().plot(
    kind="pie",
    autopct="%1.1f%%"
)

plt.title("Category Distribution")
plt.ylabel("")
plt.show()

# Box Plot

plt.boxplot(data["Sales"])

plt.title("Sales Distribution")
plt.ylabel("Sales")
plt.show()

print("\nSales Data Analysis Completed Successfully!")

Step 1: Import Required Libraries
Two Python libraries are used:
- Pandas: Used for loading, cleaning, manipulating, and analyzing data.
- Matplotlib: Used for creating graphs and charts.

Step 2: Load CSV File
- The Superstore dataset is loaded from a CSV file.
- The dataset is stored in a DataFrame named csv_data.
- Latin-1 encoding is used to handle special characters in the dataset.

What is CSV?
CSV stands for Comma-Separated Values. It stores tabular data in rows and columns, with values separated by commas.

Step 3: Create Excel and JSON Files
The CSV dataset is converted into two other formats:
1. Excel: The data is saved as Superstore.xlsx.
2. JSON: The data is saved as Superstore.json.

What is Excel?
Excel is a spreadsheet file format used to store and organize data in rows and columns.

What is JSON?
JSON stands for JavaScript Object Notation. It stores data in key-value pairs and is commonly used for exchanging data between applications.

Step 4: Load Data from All Three Formats
The program loads the data from:
- CSV file.
- Excel file.
- JSON file.
The first five records of each dataset are displayed.

Step 5: Check Data
In this step, we check the quality of the dataset.

1. Null Values
- Identifies missing values in each column.
- Helps us understand which columns contain incomplete information.
2. Duplicate Records
- Counts repeated rows in the dataset.
- Helps identify unnecessary duplicate information.

Step 6: Data Cleaning
Data cleaning is performed to improve data quality.

Two operations are performed:

1. Remove Missing Values
- Records containing missing values are removed.
- This creates a dataset without missing entries.
2. Remove Duplicate Records
- Repeated rows are removed.
- Only unique records are retained.
The cleaned dataset is stored in a new DataFrame named data.

Step 7: Data Transformation
Data transformation means converting data into a suitable format for analysis.

Two operations are performed:

1. Convert Order Date
- The Order Date column is converted into datetime format.
- This makes date-based operations easier.
2. Calculate Profit Percentage

The profit percentage is calculated to understand how much profit is earned compared with sales.

Formula:Profit Percentage = (Profit / Sales) × 100

Step 8: Data Analysis
In this step, important sales statistics are calculated.

1. Total Sales

2. Average Sales

- Helps understand the average value of sales transactions.
3. Total Profit

4. Sales by Category

Step 9: Bar Chart – Sales by Category

Step 10: Pie Chart – Category Distribution
- A pie chart is created to show the distribution of records across product categories.
- Each slice represents one category.
- The percentage of each category is displayed.

Step 11: Box Plot – Sales Distribution
- A box plot is created to display the distribution of sales values.
- It shows the median, quartiles, and potential outliers.
Purpose: To understand the spread of sales values and identify unusually high or low sales transactions.

Introduction to PCA
PCA (Principal Component Analysis) is a dimensionality reduction technique used in machine learning.
- It reduces the number of features in a dataset.
- It converts original features into new features called Principal Components.
- It helps to reduce data complexity.
- It retains maximum possible information from the original dataset.
- It is useful for data visualization and faster processing.
