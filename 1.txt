# DNA Sequence Analysis

dna = input("Enter DNA Sequence: ").upper()

# Length
print("\nSequence Length:", len(dna))

# GC Content
g = dna.count("G")
c = dna.count("C")

gc = ((g + c) / len(dna)) * 100

print("GC Content:", round(gc, 2), "%")

# Motif Search
motif = input("Enter Motif: ").upper()

positions = []

for i in range(len(dna) - len(motif) + 1):
    if dna[i:i + len(motif)] == motif:
        positions.append(i)

print("Motif Found At:", positions)

# Start Codon
start = dna.find("ATG")

if start != -1:
    print("Start Codon Found At:", start)
else:
    print("Start Codon Not Found")

# Stop Codons
stop_codons = ["TAA", "TAG", "TGA"]

for stop in stop_codons:
    pos = dna.find(stop)

    if pos != -1:
        print(stop, "Found At:", pos)

# Reverse Complement
reverse = dna[::-1]

complement = ""

for base in reverse:
    if base == "A":
        complement += "T"
    elif base == "T":
        complement += "A"
    elif base == "G":
        complement += "C"
    elif base == "C":
        complement += "G"

print("Reverse Complement:", complement)




**Enter DNA Sequence: ATGCGATACGCTTGA ( output)

This program performs DNA sequence analysis using Python.
It calculates the total length and GC content (percentage of G and C bases) of the DNA sequence.
It searches for a specific motif and finds its position in the sequence.
It identifies the start codon (ATG) and stop codons (TAA, TAG, TGA).
Finally, it generates the reverse complement of the DNA sequence by replacing complementary bases (A-T and G-C).
